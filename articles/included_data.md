# Included data sets and files in the package

``` r

library(datadaptor)
library(haven)
```

### Included labelled data

The package has an included dataset `mtcars_labelled` (see documentation
with
[`?mtcars_labelled`](https://urswilke.gitlab.io/datadaptor/reference/mtcars_labelled.md))
which is a labelled version of `mtcars`. The data is also included as an
SPSS sav file
[mtcars_labelled.sav](https://urswilke.gitlab.io/datadaptor/inst/extdata/mtcars_labelled.sav).
These are generated by [this Rmd
file](https://urswilke.gitlab.io/datadaptor/devel/make_fake_data.md).
After installing the package, here is how you can access these data
sets:

