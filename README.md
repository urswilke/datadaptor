## Example

### Included labelled data

The package has an included dataset `fake_survey` with made-up data of a
survey. The data is also included as an SPSS sav file
[fake\_survey.sav](inst/extdata/fake_survey.sav). These are generated by
[this Rmd file](devel/make_fake_data.md). After installing the package,
here is how you can access these data sets:

``` r
library(datenanpassr)
# Needed for the printing of the labels when printing the dataframe:
library(tidyverse)
```
